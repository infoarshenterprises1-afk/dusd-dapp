# Demo USD (DUSD) Trust Wallet dApp

1. Deploy the DemoUSD Solidity contract on BNB Smart Chain Testnet.
2. Copy the deployed contract address.
3. Open index.html in a web host or inside a Trust Wallet dApp browser.
4. Paste the contract address and press Load Token.
5. Press Connect Trust Wallet.
6. For testing, keep the wallet on BNB Smart Chain Testnet (chain ID 97).
7. Use tBNB for gas.

This site is intentionally labeled DEMO / TEST TOKEN and uses the DUSD contract ABI. It does not represent official Tether USDT.

For a production mobile website outside Trust Wallet's dApp browser, add a WalletConnect/Reown integration with your own project ID; never put a seed phrase or private key in the website.
